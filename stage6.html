NANDだけで全部作れる

万能ゲート
🎯 ミッション
NAND が「万能ゲート」と呼ばれる理由を説明できるようになろう。NAND・NAND で NOT・NAND で AND・NAND で OR の4つの課題を解き、確認クイズに全問正解すれば合格。

ねこ博士
STAGE3 で、AND をトランジスタでどう組むかは「少し工夫が要る」と言って、先送りにしていたね。今日はその続きだ。CMOS では、出力を電源（1）につなぐ pMOS の組と、地面（0）につなぐ nMOS の組を、必ず反対の働きになるように作る。NOT のときは、pMOS 1個と nMOS 1個だった。
うさ美
片方が通すときは、もう片方が必ず通さない。だから電源と地面が直接つながらない、という話でした。
ねこ博士
そう。では入力が A と B の2本のとき、地面側に nMOS を2個、直列に並べてみる。出力が地面とつながって 0 になるのはどんなとき？
うさ美
直列だから、2つとも通すとき。nMOS は 1 で通すので、A も B も 1 のときだけ、出力が 0 になります。
ねこ博士
電源側は、その反対の働きにしなければいけない。「A と B が両方 1」以外のときに、出力を電源につなぐ。そのためには pMOS を2個、並列に置く。pMOS は 0 で通すから、A か B のどちらかが 0 なら、どちらかの pMOS が通して出力が 1 になる。
地面側：nMOS 2個を直列 → A＝1 かつ B＝1 のときだけ出力を 0 にする 電源側：pMOS 2個を並列 → A＝0 または B＝0 なら出力を 1 にする 結果：出力は「A AND B」のちょうど反対。トランジスタは 4 個
うさ美
出てきたのは AND じゃなくて、AND の反対ですね。
ねこ博士
そう。CMOS の組み方では、トランジスタを1段だけ使うと、どうしても反対の答えが出てくる。NOT のときもそうだったね。この「AND の反対」を、NOT AND を縮めて NAND（ナンド）と呼ぶ。

うさ美
じゃあ、AND を作るには NAND の後ろに NOT を付けるしかない。4個＋2個で、トランジスタが 6 個要るんですね。
ねこ博士
そういうこと。CMOS では、AND より NAND のほうが部品が少なく、速く動く。同じように考えると、nMOS を並列・pMOS を直列にした4個の回路は「OR の反対」、NOR（ノア）になる。設計者は NAND や NOR を好んで使うんだ。
ねこ博士
ここからが今日の本題だ。NAND だけで、NOT・AND・OR を全部作れるかどうか。まず NOT から。NAND は入力が2本あるけれど、NOT は入力が1本だ。どうしようか。
うさ美
2本の入力の両方に、同じ A をつないでしまうのはどうですか。A＝0 なら、0 と 0 の NAND で 1。A＝1 なら、1 と 1 の NAND で 0。反対が出てきます。
NOT A ＝ A NAND A　（NAND 1個）
ねこ博士
次は AND だ。NAND は「AND の反対」だった。
うさ美
反対の反対で元に戻すので、NAND の出力を、いま作った「NAND で作った NOT」に通せばいい。NAND 2個です。
A AND B ＝ NOT ( A NAND B ) ＝ ( A NAND B ) NAND ( A NAND B )　（NAND 2個）
ねこ博士
最後に OR。これは STAGE4 のド・モルガンの法則を思い出すといい。OR を「NOT と AND」で書いた式があったね。
うさ美
A OR B ＝ NOT ( (NOT A) AND (NOT B) ) でした。……あ、「NOT ( 何か AND 何か )」は、そのまま NAND です。だから A OR B ＝ (NOT A) NAND (NOT B)。NOT A と NOT B は、それぞれ NAND 1個で作れる。
A OR B ＝ NOT ( (NOT A) AND (NOT B) )　（ド・モルガンの法則） ＝ (NOT A) NAND (NOT B) ＝ ( A NAND A ) NAND ( B NAND B )　（NAND 3個）
ねこ博士
これで NOT・AND・OR が NAND だけで作れた。前のステージで、XOR は AND・OR・NOT から作れることも確かめたね。ということは？
うさ美
XOR も NAND だけで作れる。それに、どんな「もし〜なら」の判断も「かつ・または・でない」に分解できるなら……どんな論理回路も NAND だけで作れる、ということですか？
ねこ博士
そう。この性質を持つゲートを万能ゲートと呼ぶ。NAND は万能ゲートなんだ（NOR も同じく万能）。工場からすれば、NAND という1種類の部品をきれいに作れれば、あとは配線の問題になる。
うさ美
本物の CPU も、全部 NAND だけでできているんですか？
ねこ博士
「全部 NAND だけ」ではないんだ。実際の設計では、NAND・NOR・NOT のほかに、「AND してから OR してから反転」までをトランジスタ1段でまとめた複合ゲートなども使って、少しでも速く、少しでも電気を使わないように組んでいる。万能ゲートの話は「理屈の上では1種類で足りる」ということで、実際の CPU は、その理屈の上でいろいろな部品を使い分けている。
ねこ博士
次のステージでは、いよいよ足し算の回路を作る。ここからは、NAND で作れることが分かった AND・OR・XOR を、また箱として使っていこう。

確認クイズ

Q1. CMOS の NAND は、トランジスタをどう組んだもの？

正解！ nMOS の直列は「両方 1 のときだけ」地面とつながり出力 0。電源側はその反対になるよう pMOS を並列にする。逆の組み方は NOR になる。

Q2. NAND の2本の入力に同じ信号 A をつなぐと、何になる？

正解！ A＝0 なら 0 NAND 0＝1、A＝1 なら 1 NAND 1＝0。反対が出てくるので NOT。

Q3. 「NAND は万能ゲート」の正しい意味は？

正解！ NOT・AND・OR が NAND で作れるので、理屈の上ではどんな回路も NAND だけで作れる。実際の CPU は NOR や複合ゲートなども使い分けている。
