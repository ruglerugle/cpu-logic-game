STAGE 9

選ぶ回路とALU

マルチプレクサ
🎯 ミッション
マルチプレクサで計算の種類を切り替えるしくみ（ALU）を説明できるようになろう。マルチプレクサ・AND/OR 切り替え・ゼロ判定の3つの課題を解き、確認クイズに全問正解すれば合格。
未達成
ねこ博士
ここまでで、AND・OR・XOR・足し算・引き算の回路がそろった。プログラムの命令には「足せ」「引け」「AND を取れ」といろいろあるけれど、CPU の中で計算を担当する部品は1つなんだ。ALU（算術論理演算装置。算術＝足し算や引き算、論理＝AND や OR）と呼ぶ。1つの部品が、命令ごとに違う計算をするには、どうすればいいと思う？
うさ美
計算ごとに回路を作り直す……のは無理ですよね。回路は配線なので、途中で変えられない。
ねこ博士
そう、配線は変えられない。そこで、発想を変える。全部の計算回路を並べておいて、全部いっぺんに計算させてしまう。そして出口で、命令が求める1つの答えだけを選んで通す。必要なのは「選ぶ回路」だ。
うさ美
計算した答えの大半は捨てるんですか。もったいない気もします。
ねこ博士
回路は、入力が来れば勝手に答えを出す。止めておくほうが手間なんだ。だから「全部計算して、1つ選ぶ」が一番速くて簡単なんだよ。では、選ぶ回路から作ろう。入力は A と B の2本、それと選択信号 SEL。SEL＝0 なら A を、SEL＝1 なら B を出口 OUT に通す。
ねこ博士
まず、A のための「門」を考えよう。SEL＝0 のときだけ A を通し、SEL＝1 のときは 0 にしてしまう門は、どう作れる？
うさ美
「A かつ SEL が 0」のときに 1 にしたいので、A AND (NOT SEL)。SEL＝1 なら NOT SEL が 0 だから、A が何でも 0 になります。
ねこ博士
B のほうは？
うさ美
SEL＝1 のときだけ通すので、B AND SEL。……2つの門のうち、どちらか片方は必ず 0 なので、OR でまとめれば、開いているほうの値が出てきます。
OUT ＝ ( A AND (NOT SEL) ) OR ( B AND SEL ) SEL＝0：左の門が A を通し、右の門は 0 → OUT＝A SEL＝1：左の門は 0、右の門が B を通す → OUT＝B
ねこ博士
この「選択信号でどの入力を通すか選ぶ回路」をマルチプレクサ（多くのものを1本にまとめる装置、という意味）、または選択回路と呼ぶ。
うさ美
選ぶものが4つになったら？
ねこ博士
選択信号を2ビットにすれば、4通りを指定できる。マルチプレクサを3つ、トーナメントのように組めばいい。1回戦で SEL の下の桁を使って「1番と2番」「3番と4番」から1つずつ選び、決勝で上の桁を使ってどちらかを選ぶ。8つなら3ビット、16なら4ビット。nビットの選択信号で、2をn回掛けた数の中から1つを選べる。
うさ美
STAGE1 の「nビットで表せる数は2をn回掛けた数」と同じですね。選択信号は「何番を選ぶか」という番号そのものなんだ。
ねこ博士
では ALU の小さな模型を作ろう。A と B の AND と OR を両方計算しておいて、演算の種類 OP が 0 なら AND の答え、1 なら OR の答えを出す。
計算回路は全部同時に答えを出し、演算の種類（OP）でマルチプレクサが1つを選ぶ。答えといっしょに「0だったか」「桁あふれしたか」などのフラグも出す。
ねこ博士
ALU は答えといっしょに、答えについての短い報告も出す。前のステージで出てきた「桁あふれが起きたか」のフラグのほかに、よく使うのが「答えがちょうど0だったか」のフラグ（ゼロフラグ）だ。3ビットの答え R2 R1 R0 がすべて 0 のときだけ 1 になる回路を考えてごらん。
うさ美
全部が 0 ということは、「少なくとも1つが 1」の反対です。だから NOT ( R2 OR R1 OR R0 )。OR を2つつないで3本をまとめて、最後に NOT。
うさ美
0 かどうかが、どうしてそんなに大事なんですか？
ねこ博士
「2つの数が等しいか」を調べるのに使えるからだ。A − B を計算して、答えが 0 なら A と B は等しい。ゼロフラグが立っていれば「等しい」、立っていなければ「違う」。マイナスかどうか（一番左のビット）も見れば、大小も分かる。プログラムの「もし x が 5 より小さければ」という判断は、CPU の中では引き算をしてフラグを見る、という形で行われているんだ。
うさ美
引き算1つで、比べる仕事まで済んでしまうんですね。STAGE5 では XOR で一致を調べましたけど、ALU はもう引き算を持っているから、それを使い回すほうが部品が少ない。
ねこ博士
そういうこと。ALU はこれで、計算も比較もできるようになった。でも、まだ足りないものがある。計算した答えを覚えておくことと、命令を順番にこなしていくこと。それが最後のステージだ。

確認クイズ

Q1. ALU が「足し算」と「AND」を切り替える方法として正しいのは？

正解！ 配線は変えられない。全部いっぺんに計算させ、出口で選ぶのがいちばん速く簡単。

Q2. マルチプレクサ OUT＝(A AND NOT SEL) OR (B AND SEL) で、SEL＝1、A＝1、B＝0 のとき OUT は？

正解！ SEL＝1 なので左の門は 0、右の門が B を通す。B＝0 なので OUT＝0。

Q3. CPU が「A と B は等しいか」を調べる方法として、この章で説明したものは？

正解！ 等しければ差は 0。ALU が出すゼロフラグを見れば判定できる。一番左のビットも見れば大小も分かる。
